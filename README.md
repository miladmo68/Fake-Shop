## 🚀 Getting Started

**Prerequisites:** [Node.js](https://nodejs.org/) 18 or newer

**Install and run**

```bash
git clone https://github.com/miladmo68/Fake-Shop.git
cd Fake-Shop
npm install
npm run dev
```
